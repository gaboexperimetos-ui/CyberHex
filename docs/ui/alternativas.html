CyberHex · 5 direcciones · PC + móvil

Cada pestaña es una propuesta visual radicalmente distinta de la anterior, con maqueta de escritorio y de móvil. Revísalas y dime qué corregir. La primera pestaña explica qué elementos tiene una interfaz.

01 · Estructura

Contenedores y navegación

  • Barra superior / AppBar — título, acciones, volver.
  • Cabecera editorial — ceja + titular + subtítulo.
  • Navegación — rail lateral, tabs, barra inferior.
  • Área de contenido — scroll, rejilla, columnas.
  • Hoja / modal — panel que sube desde abajo.
02 · Contenido

Lo que se lee y se ve

  • Texto — display, título, cuerpo, leyenda, mono.
  • Imagen — carátula, miniatura, backdrop.
  • Lista / Rejilla — filas, tarjetas, raíles.
  • Tarjeta — grupo con borde, sombra o cristal.
  • Datos — cifras, tiempos, barras, gráficos.
03 · Controles

Lo que se toca

  • Botones — relleno, tonal, contorno, icono.
  • Chips / Filtros — etiquetas seleccionables.
  • Deslizador / Interruptor — volumen, progreso, on/off.
  • Campo de texto — búsqueda, nombre.
  • Menú / Acción — kebab, contextual.
04 · Estado y feedback

Qué pasa y qué se siente

  • Vacío — pantalla sin datos.
  • Cargando — spinner, barra, esqueleto.
  • Progreso — línea, anillo, porcentaje.
  • Aviso — snackbar, toast, error.
  • Háptica / Sonido — respuesta al tocar.
05 · Lenguaje visual

Color, tipo, espacio, forma

  • Paleta — fondo, superficie, acento, texto.
  • Tipografía — display, título, cuerpo, mono.
  • Espaciado — ritmo vertical, márgenes, aire.
  • Radios y bordes — redondeo, grosor, sombra.
  • Movimiento — transiciones, animación, scroll.
06 · Piezas de CyberHex

Lo que ya existe

  • Mini-reproductor — píldora persistente.
  • Reproductor completo — carátula + controles.
  • Biblioteca — canciones, álbumes, carpetas.
  • Listas / Radios / Descargas — colecciones.
  • Ajustes / Estadísticas — config e historial.
